# 04 — 过站台、SN、防跳站与谱系（黄金路径核心）

**What to build:** 操作工在过站台选择工位后，对到达本工序的个体执行过站：首站成功时创建或扫入成品 SN 并挂工单（工单进入生产中）；后续站防跳站；指定工序绑定关键件 SN；合格前进。可按成品 SN 查询谱系（过站履历+关键件）。过站台为大字扫码优先布局，而非管理端表格缩小版。

- [ ] 关键件绑定进入谱系并按规则记耗
- [ ] 谱系查询可还原站点与关键件
- [ ] 过站与绑定可审计；未领料/未齐套策略按配置提示或拦截（默认与 CONTEXT 一致）
