# 08 — 装配绑定与三种粒度物料耗用

**What to build:** 让操作工在装配过程中按执行快照要求采集关键件 SN、批次 Lot 或数量耗用，并使每次绑定、替换和冲正都能从成品正查或从部件反查。

**Blocked by:** 06 — 线边物料交接与工单发料事务账; 07 — 受控产品身份、标签事件与 START_WIP.

**Status:** ready-for-agent

- [ ] 执行快照为每项直接物料指定 SN、Lot 或数量追溯粒度和装配工序。
- [ ] 关键件在绑定具体部件 SN 时生成有效部件关系和实际耗用事务。
- [ ] Lot 件记录供应/生产 Lot 与实际数量；数量件按批准规则记录逐 SN 耗用或订单回冲。
- [ ] 同一关键部件 SN 默认不能同时存在于两个有效成品关系中，并发绑定只能成功一次。
- [ ] 未交接、未发料、物料不匹配、工序不匹配或余额不足时装配被拒绝且不产生部分事实。
- [ ] 解绑、替换和纠错引用原关系与原事务，追加反向或补偿事实而不删除历史。
- [ ] 工位端明确显示待采集物料、已采集关系和剩余要求，避免把发料误认为耗用。
- [ ] 可按成品 SN 正查绑定和耗用，也可按关键件 SN 或 Lot 反查受影响成品。
- [ ] 公共 API 与 SQL Server 测试覆盖三种粒度、重复绑定、并发、冲正和事务原子性。
