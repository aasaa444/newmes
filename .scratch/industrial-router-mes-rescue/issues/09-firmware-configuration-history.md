# 09 — 固件与配置执行履历

**What to build:** 让操作工按订单冻结要求执行工业路由器固件和配置写入，并保留要求版本、实际结果、工具和校验信息；失败后的重试不能覆盖原失败。

**Blocked by:** 08 — 装配绑定与三种粒度物料耗用.

**Status:** ready-for-agent

- [ ] 订单执行快照包含批准的固件、配置包和必要校验要求，后续模板变化不影响在制 SN。
- [ ] 每次执行记录要求版本、实际版本、配置包、校验值、工具/设备、主体、开始/结束时间和结果。
- [ ] 具体固件值和设备参数来自版本化配置或适配器，不作为通用工业路由器常量写死。
- [ ] 执行失败保留独立记录和诊断信息；重试产生新记录并关联原失败。
- [ ] 工序不正确、要求缺失、校验失败或订单暂停时不能记录为成功并推进路线。
- [ ] 工位端显示冻结要求、当前执行状态和明确失败处理入口。
- [ ] 重复命令、并发执行和数据库失败不会生成多个成功结果或部分过站事实。
- [ ] 谱系查询能够读取全部固件与配置执行历史，包括失败和重试。
