# 14 — 成品仓储交接

**What to build:** 让仓储交接员明确接受或拒绝制造完工成品，把车间制造完成与仓储责任转移分开记录，并让计划员看到仍待交接或被拒绝的成品。

**Blocked by:** 13 — 终检与制造完工门禁.

**Status:** ready-for-agent

- [ ] 只有制造合格完工且未完成有效交接的 SN 可以发起仓储交接。
- [ ] 交接请求和回执具有稳定业务幂等键，重复接受不会重复增加成品责任数量。
- [ ] 仓储交接员可以接受或带原因拒绝；拒绝不撤销制造完工事实。
- [ ] 制造完工时间、交接发起时间、仓储接收时间和当前责任状态分别可查。
- [ ] 交接工作台列出待接收、已接收和已拒绝项目，并提供关联订单、SN 与原因。
- [ ] 无权限角色、未完工 SN、报废 SN 和冲突回执被服务端拒绝。
- [ ] 接受、拒绝、重复回执和事务失败在公共 API 与真实 SQL Server 上验证。
- [ ] 完整谱系可读取仓储交接历史，但不会把仓储接收表述为 ERP 已入账。
