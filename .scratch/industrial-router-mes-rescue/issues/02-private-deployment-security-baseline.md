# 02 — 建立私有化运行安全基线

**What to build:** 让 IT 运维人员能够以单厂私有化试点方式安全启动系统，并在配置不符合生产基线时得到阻断，而不是把演示密钥、开放跨域、高权限数据库账号或 Development 行为带进正式环境。

**Blocked by:** 01 — 建立可演进的 SQL Server 数据库基线.

**Status:** ready-for-agent

- [ ] 正式拓扑只通过反向代理的 HTTPS 入口对用户开放，API 和 SQL Server 保持在内部网络。
- [ ] 密钥、证书和数据库凭据来自外置配置，不写入镜像、前端包、仓库文件或日志。
- [ ] 检测到示例密钥、演示账号初始化、开放 CORS、高权限数据库账号或 Development 环境时，生产就绪检查失败。
- [ ] 存活检查只证明进程存活，就绪检查验证数据库兼容性和必要依赖，二者不泄露敏感信息。
- [ ] 结构化日志带有关联 ID，能够连接一次用户请求、领域操作和集成尝试，但不记录令牌或密码。
- [ ] 部署冒烟验证 HTTPS、内部端口隔离、非生产初始化关闭、最小权限连接和关键页面/API 可用。
- [ ] 安全基线的失败条件均有自动化或可重复检查，不依赖人工查看配置文件。
