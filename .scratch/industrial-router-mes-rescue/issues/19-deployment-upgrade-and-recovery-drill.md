# 19 — 私有化部署、升级与恢复演练

**What to build:** 让 IT 运维人员能够从干净主机安装系统、从上一候选版本升级、执行备份并在隔离环境恢复，然后用固定 SN 冒烟证明恢复的数据和应用可用。

**Blocked by:** 02 — 建立私有化运行安全基线; 17 — 收缩并隔离旧执行路径.

**Status:** ready-for-agent

- [ ] 私有化部署从空环境启动反向代理、应用和 SQL Server，显式执行 Migration 后通过 HTTPS 冒烟。
- [ ] 上一候选版本带代表性数据的环境可以备份、升级并继续查询旧数据和执行新订单。
- [ ] 升级失败会停止发布并保留可恢复状态，不自动删库或以空库继续运行。
- [ ] 每日完整备份和升级前备份流程可重复执行，备份文件与运行数据库分离保存。
- [ ] 备份可以恢复到隔离环境，恢复过程记录开始/结束时间、结果、操作者和校验信息。
- [ ] 恢复后验证数据库版本、用户登录、固定 SN 谱系、待处理 Outbox 和关键业务冒烟。
- [ ] 实测恢复点与恢复时间被记录并与暂定 RPO 24 小时、RTO 4 小时比较，不把暂定目标表述为已达标。
- [ ] 部署、升级、备份和恢复过程不暴露密钥，不默认创建演示账号或数据。
- [ ] 运维说明由未参与开发的人按步骤复现一次并记录发现的问题。
