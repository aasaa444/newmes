# 07 — 受控产品身份、标签事件与 START_WIP

**What to build:** 让操作工使用来自授权来源的成品身份开始一件产品的制造，并把身份、订单和执行快照正式关联；标签打印和补打有独立历史，不能把随机字符串当成未经授权的产品身份。

**Blocked by:** 03 — 建立可组合角色与业务审计上下文; 05 — 生产订单下达、执行快照与受控生命周期; 06 — 线边物料交接与工单发料事务账.

**Status:** ready-for-agent

- [ ] 成品 SN 来源和分配时机按订单快照策略选择 ERP、标签系统或 MES 受控发号适配器。
- [ ] MAC、IMEI、证书等受控身份只能从授权适配器或号池取得，演示值明确标记为非生产。
- [ ] `START_WIP` 将已有身份与订单、产品和执行快照关联，并追加投产制造事件。
- [ ] 未下达、已暂停、已完成、已关闭或已取消订单拒绝投产；超出计划数量按明确策略拒绝。
- [ ] 重复提交同一投产命令返回原结果，不重复增加投产数或制造事件。
- [ ] 身份分配、绑定、解绑、作废以及标签打印、补打、作废和换标分别保留事件与原因。
- [ ] 工位端显示身份来源、当前订单和首个应执行工序，并对错误身份给出中文处理建议。
- [ ] 身份唯一性、并发投产、暂停门禁、标签历史和订单数量平衡在 SQL Server 上验证。
