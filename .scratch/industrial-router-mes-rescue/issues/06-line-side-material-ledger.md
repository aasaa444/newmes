# 06 — 线边物料交接与工单发料事务账

**What to build:** 让物料人员按清晰责任边界记录物料进入 MES 线边范围、分配到生产订单以及后续退料或冲正；当前余额来自只追加事务，而不是可直接改写的库存数字。

**Blocked by:** 03 — 建立可组合角色与业务审计上下文; 05 — 生产订单下达、执行快照与受控生命周期.

**Status:** ready-for-agent

- [ ] 物料交接记录来源单据、物料、Lot、数量、单位、交接双方和业务幂等键，并增加线边可用量。
- [ ] 工单发料只把线边可用量分配给指定订单，不生成产品实际耗用。
- [ ] 交接、发料、退料、冲正和调整分别形成只追加事务；更正引用原事务并要求原因。
- [ ] 线边余额和工单可用量由事务投影得到，普通业务接口不能直接设置聚合总数。
- [ ] 默认拒绝未授权负库存、超量发料、重复交接和错误计量单位，并返回可行动说明。
- [ ] 物料工作台可按物料、Lot、订单和事务类型查看余额来源及历史。
- [ ] 物料交接员拥有操作权限，操作工和无关角色只能按职责读取或被拒绝。
- [ ] SQL Server 测试覆盖并发发料、重复幂等键、冲正和事务失败不产生部分余额。
