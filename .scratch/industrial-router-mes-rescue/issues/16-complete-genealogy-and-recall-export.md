# 16 — 完整单件谱系与召回反查导出

**What to build:** 让质量、客诉和计划人员可以按成品 SN 还原从订单执行依据到仓储与 ERP 状态的完整历史，也可以从关键件 SN 或 Lot 反查受影响产品，并生成可校验的证据导出。

**Blocked by:** 08 — 装配绑定与三种粒度物料耗用; 09 — 固件与配置执行履历; 10 — 版本化测试规范与逐项测试执行; 11 — 不合格记录与质量保留; 12 — 质量处置、返工与复测闭环; 13 — 终检与制造完工门禁; 14 — 成品仓储交接; 15 — 事务 Outbox、ERP 回执、对账与关单.

**Status:** ready-for-agent

- [ ] 成品 SN 查询包含订单及冻结快照、身份/标签、工序事件、操作主体和时间位置。
- [ ] 查询包含关键件关系、Lot/数量耗用、解绑替换和冲正历史，而不是只显示当前绑定。
- [ ] 查询包含固件/配置、全部测试执行与测量、原始报告引用、失败和复测关系。
- [ ] 查询包含不合格、保留、处置、返工、报废/完工、仓储交接、Outbox 和 ERP 回执状态。
- [ ] 可以按关键件 SN 或 Lot 反查所有相关成品，并区分有效关系与历史已替换关系。
- [ ] 上游 PCBA 等外部履历只显示有来源的外部引用，不生成虚假本厂事件。
- [ ] 导出包含查询条件、系统/规格版本、生成时间和完整性校验值；相同数据可复核校验。
- [ ] 追溯端支持授权查询、清晰空状态和大结果分页，不向无权限角色暴露敏感证据。
- [ ] 固定 SN 的正查、关键件/Lot 反查和导出内容由公共 API、浏览器和 SQL Server 测试验证。
