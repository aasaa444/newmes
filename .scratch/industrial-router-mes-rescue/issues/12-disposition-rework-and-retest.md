# 12 — 质量处置、返工与复测闭环

**What to build:** 让授权质量工程师对不合格作出返工、报废或有依据的让步接收决定，并让返工产品按批准作业和复测要求闭环；任何处置都不能删除原失败。

**Blocked by:** 11 — 不合格记录与质量保留.

**Status:** ready-for-agent

- [ ] 质量工程师可以选择返工、报废或让步接收，并必须记录理由、授权主体和适用依据。
- [ ] 返工处置引用已批准的返工作业或路线版本，明确回到的工序和必须完成的复测。
- [ ] 返工执行、部件替换/物料冲正和复测分别追加事实，并通过因果关系连接原失败和处置。
- [ ] 原测试失败、不合格和保留历史始终可查；复测通过不会修改原记录。
- [ ] 只有处置条件和要求复测全部满足后，授权质量角色才能解除保留。
- [ ] 报废使 SN 进入不可恢复的终态并更新订单数量平衡；相关物料责任按批准规则记录而非删除耗用。
- [ ] 让步接收缺少有效审批依据时被拒绝；操作工、产线主管和系统管理员不能代替质量批准。
- [ ] 质量工作台完整展示处置、返工任务、复测状态和可执行的下一动作。
- [ ] 自动化测试覆盖三种处置、非法放行、返工复测、报废终态、权限分离和并发处置。
