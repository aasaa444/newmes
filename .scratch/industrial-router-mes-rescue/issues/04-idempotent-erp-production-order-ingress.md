# 04 — ERP 幂等生产订单入站

**What to build:** 让 ERP 或演示适配器通过同一正式契约向 MES 下发生产订单；计划员可以看到订单被接受或拒绝的结果，重复和冲突消息不会制造重复订单或静默覆盖数据。

**Blocked by:** 01 — 建立可演进的 SQL Server 数据库基线; 03 — 建立可组合角色与业务审计上下文.

**Status:** ready-for-agent

- [ ] 入站消息保存来源系统、消息 ID、业务键、来源版本、契约版本、载荷校验信息和处理状态。
- [ ] 首次有效订单消息创建一张状态为“已接收”的 MES 生产订单，并返回稳定接受结果。
- [ ] 相同来源和消息 ID 的完全重复请求返回原结果，不再次创建订单或审计事实。
- [ ] 幂等键相同但载荷冲突的请求被明确拒绝并保留诊断信息，不覆盖已有订单。
- [ ] 缺少必填字段、未知主数据或不支持契约版本时返回稳定错误码和可行动中文说明。
- [ ] ERP 模拟器必须经过相同入站契约和 Inbox 处理，不能直接写 MES 订单表。
- [ ] 计划员可以在订单工作台查看已接收订单、来源版本和入站处理结果；无权限用户不能下发订单。
- [ ] 真实 SQL Server 集成测试覆盖重复、冲突、事务回滚和并发提交同一消息。
