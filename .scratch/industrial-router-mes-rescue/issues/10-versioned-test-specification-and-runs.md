# 10 — 版本化测试规范与逐项测试执行

**What to build:** 让质量工程师批准版本化测试规范，让测试操作员为每个 SN 保存逐项测量、设备和原始报告引用，并由冻结规范完成判定；一次失败不得被后续通过覆盖。

**Blocked by:** 05 — 生产订单下达、执行快照与受控生命周期; 09 — 固件与配置执行履历.

**Status:** ready-for-agent

- [ ] 测试规范版本定义适用产品/工序、必测项目、数据类型、单位、上下限或其他判定规则及审批状态。
- [ ] 只有已批准且适用的测试规范可以进入订单执行快照；具体阈值不从前端或互联网资料推断。
- [ ] 一次测试执行保存 SN、规范版本、设备、夹具、主体、起止时间、总体结果和原始报告引用。
- [ ] 每项测量独立保存原始值、规范单位、判定结果和必要诊断，必测项缺失时总体不能通过。
- [ ] 已确认测试执行和测量不可由普通更新接口修改；修正或复测创建新记录并引用原执行。
- [ ] 工序错误、订单暂停、规范不适用和设备数据不完整时拒绝确认测试结果。
- [ ] 测试工作台显示冻结规范、逐项测量、失败原因和历史运行，不只展示最后一次 Pass/Fail。
- [ ] SQL Server 测试覆盖边界值、单位/精度、缺项、重复提交、失败复测和事务回滚。
