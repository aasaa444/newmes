# 04 — 工单工作台（生产执行）

**What to build:** 计划员默认落地的工单一等公民界面：列表、筛选、中文状态、已领料/未领料可见，下达/领料/关闭等计划动作入口；与经营总览工单指标下钻一致。经营者只读；服务端拒绝其写操作。

**Blocked by:** 02 — 管理端经典壳（侧栏五菜单 + 顶栏）

**Status:** ready-for-agent

- [ ] 管理端「生产执行」下可打开工单工作台并完成列表/筛选
- [ ] 领料状态在列表上可辨；计划员可执行下达/领料/关闭等既有动作
- [ ] 状态等展示为中文（用户可见）
- [ ] 经营者可看不可写
- [ ] 相关 API/UI 行为有测试或一期回归不挂
