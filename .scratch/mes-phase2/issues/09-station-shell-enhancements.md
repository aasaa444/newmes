# 09 — 过站端现场增强

**What to build:** 过站端保持全屏扫码主路径：工位按工艺序展示；提示当前成品 SN 应处工序/下一站；不合格与隔离入口清晰；权限允许时提供返回管理端。不把管理端侧栏菜单搬进过站端；一期过站/绑定/防跳站/质量主路径不回归。

**Blocked by:** 01 — 经营者角色 + 登录默认落地 + 能力声明；02 — 管理端经典壳（侧栏五菜单 + 顶栏）

**Status:** ready-for-agent

- [ ] 工位列表工艺序正确；有下一站/当前应站指引（对已存在 SN）
- [ ] 不合格/隔离等入口在过站端清晰可用
- [ ] 有权用户可从过站端回管理端
- [ ] 操作工默认仍进过站端；无管理菜单主交互
- [ ] 一期过站相关测试仍绿
