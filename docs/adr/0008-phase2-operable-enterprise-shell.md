# 二期完成定义：可运营企业壳而非模块大全或真 ERP

二期必达定为：双壳（管理端五菜单 + 过站端）、经营总览五块可下钻、工单/在制/异常工作台、经营者角色、库存与系统菜单整理、统一管理端布局规范。明确不作为二期必达：真 ERP 联调、完整 WMS/APS/SPC、多工厂、仅换皮。

价值标准是一线每日可用、效率可提升、老板可掌握运营；菜单多或真对接在无甲方时无法保证「可靠完成」。一期闭环保留为执行内核，二期补企业形态与运营工作台。真集成与广度模块留待有客户环境后再开。

**Consequences**: 二期规格与验收按完成定义七条勾选；新增能力不得挤掉总览与三工作台；ERP 仍以出站模拟+可查报文为主，直至另立集成期。
