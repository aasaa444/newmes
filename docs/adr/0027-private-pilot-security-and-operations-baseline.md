# 单厂私有化试点采用最低安全与运维基线

默认交付保持厂内 Linux 主机上的 Docker Compose，但仅由 Nginx 通过 HTTPS 对外提供同源访问，API 与 SQL Server 留在内部网络。正式环境使用外置密钥、最小权限数据库账号、受限 CORS 和非演示初始化，示例密钥或演示账号不得进入生产。系统提供不泄密的存活/就绪检查、带关联 ID 的结构化轮转日志，以及独立保存的制造事件和业务审计。数据库每日完整备份且升级前额外备份，试点目标暂定 RPO 24 小时、RTO 4 小时，并要求完成恢复演练；升级按备份、迁移、启动、健康检查和冒烟测试执行。当前不承诺零停机、高可用集群、异地灾备或企业 SSO，以免为尚无现场需求的基础设施分散领域救援投入。
