# 第一期主数据以 MES 为权威，适配器先导出

**Status:** superseded by ADR-0015

物料、BOM、工艺路线由 MES 计划端维护；ERP 适配器第一期优先实现完工/耗料等**回写（导出）**契约与用友/金蝶风格模拟，不以「从真实 ERP 导入主数据」为闭环前提。

无客户 ERP 环境时仍须可试点、可演示；中小厂常见路径也是 MES 先跑再接 ERP。若第一期做成「只读 ERP」，项目会卡死在集成环境。双向同步与冲突合并推迟——那是真集成产品能力，不是学习闭环的第一刀。

**Consequences**: 实施时要约定物料编码与 ERP 对齐方式（人工或二期导入）；面试须主动说明「执行属性在 MES、财务/总账在 ERP」，避免被理解成替代 ERP。
