# 第一期完成定义含 ERP 回写模拟器

**Status:** superseded by ADR-0024

第一期不仅交付车间黄金路径与质量异常支线，还必须交付 ERP 适配器的**回写模拟**：完工/耗料等事件生成可查询的用友/金蝶风格报文，无需连接真实 ERP。

作者目标含中小客户集成叙事与既有 SAP 接口经验迁移；若第一期只做纯车间 CRUD，面试与「可落地」叙事会在集成边界处空洞。真连用友/金蝶云依赖客户环境，不适合作为无甲方时的完成门禁；模拟器把契约与时序做实，二期再换真实适配实现。

**Consequences**: 范围含出站日志/队列查询 UI 或等价可演示物；明确不做第一期真联调、不做完整报表与压测。
