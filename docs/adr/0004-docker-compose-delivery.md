# 第一期以容器编排私有化交付

试点交付默认使用 Docker Compose（或等价方式）拉起 Web 前端、ASP.NET Core API，并连接 SQL Server（容器内或客户已有实例按实施选定）。目标是可重复安装的单厂私有化，不是公有云 SaaS。

中小厂 IT 对「一台服务器 + 容器」接受度高，与精致 Web 过站台、版本升级路径一致。传统安装包或强依赖客户自建 IIS 全集，会把第一期精力耗在安装程序而非领域闭环。离线安装包、AD 域管控等留到有真实现场约束再做。

**Consequences**: 文档需写清端口、连接字符串、备份卷与升级步骤；若客户禁止容器，再评估 IIS + Windows 服务变体，不作为默认分心项。
